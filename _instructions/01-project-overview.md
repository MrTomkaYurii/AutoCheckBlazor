# AutoCheck — Огляд проекту

## Що це

Веб-платформа для автоматичної перевірки лабораторних робіт з курсу ООП на C#.
Кафедра комп'ютерних наук, ЧНУ ім. Ю. Федьковича.

## Стек

| Компонент | Технологія |
|-----------|-----------|
| Frontend + Backend | Blazor Server (.NET 10) |
| БД | SQLite + EF Core |
| UI компоненти | MudBlazor 9 |
| Автентифікація | Keycloak 24 (OIDC) |
| Markdown | Markdig |
| Контейнеризація | Docker Compose |

## Ролі

- **Студент** — здає лаби, бачить свої оцінки, прогрес
- **Викладач** — перевіряє роботи, виставляє оцінки захисту, керує лабами/групами

## Два режими перевірки

1. **Авто-перевірка** — після здачі студентом, запускається пайплайн
2. **Ручна перевірка** — викладач відкриває GradeDialog, виставляє оцінку захисту

## Формула фінальної оцінки

```
Фінал = 0.4 × AutoScore + 0.6 × DefenseScore
```
