# UI — Сторінки і компоненти

## Студент

| URL | Компонент | Що показує |
|-----|-----------|-----------|
| `/student` | StudentDashboard | Дашборд: прогрес, картки лаб, фільтри |
| `/student/lab/{id}` | Lab | Деталі лаби: задачі, результати, diff, здача |
| `/student/grades` | Grades | Таблиця всіх оцінок |
| `/student/profile` | Profile | Профіль: email, GitHub URL, GitHub token |

## Викладач

| URL | Компонент | Що показує |
|-----|-----------|-----------|
| `/teacher` | TeacherOverview | Огляд: черга перевірки (авто-оновлення 20с), активність лаб |
| `/teacher/students` | Students | Список студентів |
| `/teacher/journal` | Journal | Журнал оцінок (сітка студенти × лаби) |
| `/teacher/labs` | LabsAdmin | CRUD лаб і завдань |
| `/teacher/groups` | Groups | CRUD академічних груп |
| `/teacher/monitoring` | Monitoring | Аналітика: розподіл оцінок, топ студентів |

## Ключові компоненти

### LabCard (Shared/LabCard.razor)
Картка лаби на дашборді студента.
- Показує статус, авто-оцінку, прогрес-бар
- Показує дедлайн (зелений/жовтий <24год/червоний прострочено)
- Після дедлайну — кнопка "Здати" заблокована
- Всі лаби клікабельні незалежно від статусу

### GradeDialog (Dialogs/GradeDialog.razor)
Модальне вікно оцінювання для викладача.
- Показує результати авто-перевірки по задачах
- Slider + quick-buttons для оцінки захисту (60/70/80/90/100)
- Розраховує фінальну оцінку наживо
- Кнопки: "Зберегти оцінку" і "Відхилити"

### Lab.razor — діалог здачі
Фази: `confirm` → `running` → `done`

**Фаза confirm:**
- Якщо нема GitHub URL → попередження з посиланням на профіль
- Якщо є URL → автоматично тягне гілки з GitHub API
- Якщо лаба має BranchName → гілка підставляється автоматично
- Студент вибирає гілку → з'являється список комітів
- Студент обирає коміт → кнопка "Здати" активна

**Фаза running:**
- Spinner + поточний крок (прогрес)

**Фаза done:**
- Нова авто-оцінка, дельта, кількість тестів

## Sidebar (Layout/Sidebar.razor)

Автоматично показує різні пункти меню залежно від ролі.
Студент: Дашборд, Оцінки, Профіль
Викладач: Огляд, Студенти, Журнал, Лаби, Групи, Моніторинг

## Keycloak тема (keycloak/themes/autocheck/)

Кастомна сторінка входу і реєстрації.
- `login.ftl` — форма входу: вибір ролі, вкладки Вхід/Реєстрація
- `register.ftl` — реєстрація: поля для студента (група, GitHub) та викладача
- `login.css` — темний glassmorphism дизайн
- Групи завантажуються динамічно з `/api/groups` (fetch з JS)
- Вибір ролі зберігається в sessionStorage між сторінками
